Playlists

"Alexa, öffne musik box und spiele <Playlist>" plays these URLs in order. With Repeat on it starts over after the last track; with it off the playlist ends there. With Announce off the music starts straight away, without Alexa saying anything first. Shuffle plays them in a random order, and Resume picks up where the playlist last stopped — worth it for audiobooks, not for children's songs.
Every URL must be https:// and deliver the MP3 directly (no preview page, no login): Dropbox links need ?dl=1, Nextcloud share links need /download, Google Drive shares usually do not work. Check URLs fetches each link the way the Echo does and reports status, content type and range support (without ranges, "resume" restarts the track).
Got a whole folder? Paste a folder share link — a FRITZ!NAS link (…/nas/filelink.lua?id=…), a Nextcloud folder share or a plain directory index — into Import folder, and every audio file listed there is added below as its own track, in the order the page lists them. Nothing is saved until you press Save Playlist.
